# Support

For product or connection help, email
[support@salestouch.io](mailto:support@salestouch.io).

Before contacting support:

1. Confirm that `https://www.salestouch.io/api/mcp` is the configured endpoint.
2. Reconnect OAuth from the MCP client.
3. Confirm that the SalesTouch workspace has an active plan and a connected
   LinkedIn account.
4. Retry a read-only call such as `linkedin_accounts`.

Include the MCP client, tool name, approximate time, public error code, and
sanitized request context. Do not include credentials, cookies, OAuth tokens,
private messages, or prospect data.
