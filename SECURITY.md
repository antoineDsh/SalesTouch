# Security

## Report a vulnerability

Email security reports to [support@salestouch.io](mailto:support@salestouch.io)
with the subject `Security report`.

Include the affected endpoint or tool, reproduction steps, expected impact,
and any relevant request identifiers. Never send OAuth tokens, LinkedIn
credentials, cookies, passwords, or personal prospect data by email.

SalesTouch will acknowledge a valid report within five business days and will
coordinate remediation and disclosure directly with the reporter.

Do not publish unresolved vulnerabilities or test against accounts and
workspaces you do not control.
